Actúa como GPT-5.5 en modo agente senior frontend, experto en Astro, TypeScript, Tailwind CSS, UI/UX premium, SEO local, accesibilidad, performance web, despliegue estático y trabajo en entorno WSL con OpenCode.

Vamos a desarrollar desde cero el frontend de CarGlow, una marca de detailing y limpieza premium de coches a domicilio en Madrid.

CONTEXTO DEL PRODUCTO
CarGlow ofrece limpieza y detailing premium a domicilio en Madrid. La propuesta principal es que el cliente no tenga que desplazarse y pueda reservar por WhatsApp. El servicio debe transmitir confianza, calidad, precisión, brillo, cuidado del vehículo y estética premium automotriz.

La fuente principal de contenido del producto incluye:
- Hero con mensaje emocional: el coche no es solo transporte, es una declaración.
- Servicio profesional a domicilio en Madrid.
- Precio inicial desde 40€ por coche.
- CTA principal: reservar cita por WhatsApp.
- Problema: polvo, contaminación, sol, microarañazos, pérdida de brillo y desgaste interior.
- Solución: agua desmineralizada, productos biodegradables premium, técnicas seguras y servicio 100% a domicilio.
- Servicios:
  - Lavado Premium Express – 40€
  - Detallado de Interiores
  - Tratamiento Cerámico & Pulido
- Sección de resultados reales antes/después.
- Testimonios.
- FAQ.
- Sobre nosotros.
- Contacto.
- Footer con legales.

ENTORNO WSL
Asume que trabajo desde Windows con WSL.

Debes:

- No usar rutas de Windows salvo que sea necesario.
- Comprobar versiones de Node, npm/pnpm y git antes de iniciar.
- Recomendar pnpm si está disponible; si no, usar npm.
- Mantener instrucciones claras para ejecutar en local.

Comandos iniciales esperados, adaptándolos al estado real del proyecto:

node -v
npm -v
git --version
pwd
ls -la

Si no existe proyecto:

npm install
npm install -D tailwindcss @tailwindcss/vite
npm install lucide-react

Si Astro/Tailwind han cambiado su instalación, comprueba la documentación local o el estado del proyecto y adapta los pasos.

ESTILO VISUAL
Trabaja con una estética premium automotriz.

Dirección visual:
- Fondo oscuro elegante en secciones clave.
- Blanco/negro/grises como base.
- Acento azul eléctrico o azul premium para CTA.
- Mucho espacio.
- Tipografía limpia.
- Cards con bordes sutiles.
- Fotografías grandes o placeholders bien preparados.
- Sensación de detailing profesional, no túnel de lavado barato.

No uses:
- Gradientes excesivos.
- Efectos chillones.
- Colores infantiles.
- Animaciones pesadas.
- Imágenes falsas que parezcan resultados reales inventados.
- Demasiado texto.
