# CarGlow Frontend

Frontend de CarGlow, servicio de detailing y limpieza premium de coches a domicilio en Madrid.

## Stack

- Astro
- TypeScript estricto
- Tailwind CSS v4 mediante Vite
- Componentes Astro
- JavaScript minimo por defecto

## Desarrollo Local

```bash
npm install
npm run dev
```

El servidor local de Astro se abre normalmente en `http://localhost:4321`.

## Build

```bash
npm run build
```

La salida de produccion se genera en `dist/`.

## Despliegue

Primera opcion recomendada: Cloudflare Pages.

- Build command: `npm run build`
- Output directory: `dist`
- Framework preset: Astro

Ver pasos completos en `DEPLOY.md`.
