# AGENTS

## Rol Del Agente

Actuar como agente senior frontend para CarGlow, con foco en Astro, TypeScript, Tailwind CSS, UI/UX premium, SEO local, accesibilidad, performance y despliegue estatico.

## Reglas De Trabajo

- Inspeccionar antes de modificar.
- Mantener cambios pequenos, claros y reversibles.
- No borrar trabajo del usuario sin confirmacion.
- No desplegar sin confirmacion explicita.
- No usar imagenes falsas como resultados reales.
- Centralizar datos configurables en `src/data/`.

## Stack Aprobado

- Astro
- TypeScript
- Tailwind CSS
- Componentes Astro
- React solo si una isla interactiva lo justifica

## Validacion

Ejecutar `npm run build` antes de cerrar iteraciones con cambios de codigo.
